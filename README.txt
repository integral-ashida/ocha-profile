【Mac / GitHub Desktop の反映手順】
1. 現在の ocha-profile フォルダを別の場所へコピーしてバックアップ。
2. GitHub Desktopで正しいリポジトリを選び、Fetch origin。
   Pull originが出たら取り込みます。競合が出た場合は上書きせず相談してください。
3. Repository → Show in Finder。
4. このZIPを解凍。中のjsフォルダから2ファイルを、既存のjsフォルダ内へコピーして置き換え。
5. 中のcss/catalog.cssだけを、既存のcssフォルダ内へコピーして置き換え。
6. GitHub Desktopの変更一覧で3ファイルを確認。
7. Summaryに「種の基本情報欄を追加」→ Commit to main → Push origin。
8. 公開反映後に詳細ページを再読み込み。

【今後編集する場所】
js/species-data.js の種ごとに次の欄を追加しています。
  bodyLength:'',
  redList:'',
  redListNote:'',
  habitat:'',
  factsSource:'',

引用符の内側に文字を入れます。末尾のカンマは残します。
以下は書式の見本です。特定の種の確認済みデータではありません。
  bodyLength:'○○–○○ mm',
  redList:'準絶滅危惧（NT）',
  redListNote:'環境省レッドリスト○○年版',
  habitat:'水生植物の多い池や湿地',
  factsSource:'著者名（年）『書名』、環境省レッドリスト○○年版',

表示名：体長／環境省レッドリスト／生息環境。
種名・学名と代表写真の間に表示します。
空欄や空白だけの項目は非表示。全項目が空欄なら情報欄全体を非表示。
redListNote は redList が記入済みの場合のみ表示。
factsSource は基本情報が1項目以上ある場合のみ表示。
カテゴリーの色分けや灰色背景のカードは使いません。
スマートフォンではラベルと値を上下に配置し、長い文章も折り返します。

ナミゲンゴロウの体長「35–43 mm」は現在の解説から転記しました。
その他の値は未入力です。分類・体長・環境の調査はこの修正には含まれません。
既存の解説、学名、並び順、写真の指定は変更していません。
新しく種を追加する場合も同じ5項目をコピーできます。項目がなくてもエラーにはなりません。
